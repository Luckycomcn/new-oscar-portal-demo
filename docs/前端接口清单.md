# WIGOS 前端接口与替换说明

核实日期：2026-10-27。适用入口为根目录 Vite/Vue 项目；`web/`、`surface.html`、`srd.html` 和原站脚本属于历史参考资源，不是当前应用入口。

主机：`https://wmo-resource-catalogue.labs.wis2dev.io`。
集合路径（下表的 C）：`/collections/wigos-observing-facility-metadata`。

## 公开接口

全部为 GET，不需要登录。实测集合、queryables 和列表响应包含 `Access-Control-Allow-Origin: *`。

| 路径 | 用途 | 项目调用 |
| --- | --- | --- |
| `/openapi?f=json` | 完整 API 定义 | 对接参考 |
| `/conformance?f=json` | 服务能力声明 | 对接参考 |
| `/collections?f=json` | 集合发现 | 对接参考 |
| `C?f=json` | 集合说明、格式和下载链接 | 对接参考 |
| `C/queryables?f=json` | 可检索字段 | 对接参考 |
| `C/schema?f=json` | 记录结构 | 对接参考 |
| `C/items?f=json` | 站点列表、搜索、分页、地图、计数 | `queryFeatures` / `searchFacilities` / `getCatalogueStats` |
| `C/items/{featureId}?f=json` | 单站完整 GeoJSON/WMDR2 属性 | `getFeature`、详情页、完整 ID 搜索、JSON 下载 |
| `C/items?f=csv` | 服务声明的 CSV 格式 | **实测 HTTP 500**，项目继续从真实站点数据生成 CSV |
| `C/tiles?f=json` | 矢量瓦片集合说明 | 当前地图使用 items + bbox |
| `/wigos-observing-facility-metadata-archive.zip` | 集合提供的每日元数据压缩包链接 | 不自动下载全库 |

原始说明：[集合](https://wmo-resource-catalogue.labs.wis2dev.io/collections/wigos-observing-facility-metadata?f=json)、[OpenAPI](https://wmo-resource-catalogue.labs.wis2dev.io/openapi?f=json)、[查询字段](https://wmo-resource-catalogue.labs.wis2dev.io/collections/wigos-observing-facility-metadata/queryables?f=json)。

## 列表参数

| 参数 | 说明 / 示例 |
| --- | --- |
| `f` | `json`、`html`、`jsonld`、`csv`；前端请求 JSON |
| `limit` / `offset` | 默认 100，limit 范围 1–1000；offset 从 0 开始 |
| `q` | 文本查询，用于站名；不用于 WIGOS ID 前缀查询 |
| `bbox` | `西经度,南纬度,东经度,北纬度`，CRS84，经度在前 |
| `datetime` | 时间或区间，例如 `2020-01-01T00:00:00Z/..`；低层客户端支持，未新增 UI |
| `properties` | 属性投影；轻量查询使用 `title`，详情不限制属性 |
| `skipGeometry` | `true` 时省略几何 |
| `sortby` | `title`、`-title`、`-created` 等 |
| `facilityType.id` | `landFixed` 等 WMDR 类型代码 |
| `territories.territory.id` | `CHE` 等三字母地域代码，不是旧 OSCAR 数字 ID |
| `wmoRegion.id` | WMDR 区域代码 |
| `observations.observedProperty.id` | 观测变量代码 |
| `observations.programAffiliations.programAffiliation.id` | `GBON` 等计划代码 |
| `contacts.name` / `contacts.organization` | 内嵌联系人名称 / 机构字段匹配 |

其余可筛选字段以 queryables 为准；不能将旧系统所有高级条件直接当作目录参数。

列表返回 `features`、`numberMatched`、`numberReturned`、`links`、`timeStamp`。记录 ID 是完整 WIGOS 标识；坐标为 `[lon, lat, elevation?]`。主要业务属性包括 `title`、`facilityType`、`territories`、`wmoRegion`、`observations`、`contacts`、`created`、`updated`；代码引用使用 `{id, url, title?}`。

## 替换范围

- 首页统计、地图、主搜索和详情原本已部分使用 `src/api/wigos.ts`，本次沿用并核实。
- 完整 WIGOS ID 通过 `/items/{id}` 查询，避免当作站名传入 q；空 ID 下拉从远端分页读取。部分 ID 输入仍使用本地 ID 快照，因为目录未提供 ID 前缀查询字段。
- 联系人下拉从站点 `contacts` 读取，使用 `站点ID#数组索引` 打开详情。名称筛选使用 `contacts.name` 字段匹配；分页单位为站点，不是联系人。旧数字联系人链接保留本地快照。
- 删除报告下载中四个猜测的 `/rest/api/...` 地址及开发、预览旧 OSCAR 代理。JSON 下载返回真实原始 GeoJSON；CSV/XML 为真实记录的前端转换。XML 是应用报告格式，不代表原始 WMDR XML。当前页面原有 PDF/CSV/XML 生成器继续基于真实详情数据运行。
- 报告请求失败或 404 不再生成虚构站点；下载错误响应不会当成文件保存。
- 更新日期优先读取 `updated`。取消请求不与其他视图共享缓存请求，并正确处理调用前已经取消的 signal。
- 修复地图国界静态文件扩展名，使路径与 `public/data/world-countries.geojson` 一致。

## 能力边界与保留项

该集合提供观测设施元数据读取，不提供本项目所需的登录、用户管理、站点保存、反馈提交、仪器目录、站群目录、文献目录或 OSCAR 导出任务管理接口。OpenAPI 中的 processes/jobs 是元数据处理服务，不能替代这些业务接口。这些页面继续属于本地演示。

联系人通用搜索页也已接入站点内嵌 contacts，支持名称/机构筛选及站点分页；结果数量表示当前页联系人数量。国家、类型、观测变量等下拉保留 WMDR 静态词表，旧站点分类词表也保留，不虚构远端词表接口。

旧兼容方法 `searchApprovedStationNames`、`searchStations` 在请求失败时仍回退快照；主搜索和主详情显示真实请求错误。多选高级封装目前只把每类第一个值传到服务端，再对当前页细化，**不保证多选 OR 全量结果与总数**；当前主搜索每类只选择一个值。旧兼容搜索的 classes/operation 不是已经接通的服务端筛选。

复制 `.env.example` 到 `.env.local` 可修改 `VITE_WIGOS_API_BASE`，需重启开发服务或重新构建。默认直接跨域访问，不再依赖 `/rest` 代理。

回归测试执行实际 TypeScript 客户端，替换 HTTP 边界，覆盖 URL 参数、完整 ID 路由、bbox、预取消请求、原始 JSON 下载、内嵌联系人、404 和旧 REST 地址移除。测试不等同于完整浏览器交互验收。


## 详情页下载更新

详情页下载现使用 `src/utils/catalogueDownload.ts`。每次下载均绕过视图缓存重新请求完整站点记录：JSON 保存原始 GeoJSON；CSV 将全部嵌套字段展开为 field/value 两列；XML 从记录的 original 链接访问官方 OAI 源，提取 metadata 中的原始 WMDR XML。没有 PDF 下载接口，菜单项已禁用并说明原因。HTTP 错误、无记录及 XML 源错误直接提示，不回退演示文件。

XML 使用固定 `/wmdr-source` 代理，开发和 preview 由 Vite 提供，Docker 部署由 nginx.conf 提供；其他纯静态托管环境必须配置同一路径代理。已实测该代理返回 HTTP 200 且无 OAI 错误。

地图弹窗的 XML、CSV、JSON 下载也已统一调用 downloadCatalogueRecord，每次重新请求真实完整记录，不再依赖弹窗摘要或本地示例。PDF 入口保持注释。

## 导出页面实时数据更新

`#/export` 已移除本地站点列表、模板和随机字段。批量导出通过 `searchFacilities` 按 250 条分页获取真实记录，可选择目录全部记录或搜索页保存的完整筛选条件，不再仅导出当前页 ID。旧的无 query 搜索快照不支持筛选导出，需重新搜索。支持进度、取消、错误提示；出错时不提供部分文件。摘要字段与完整元素集区分导出，CSV 的嵌套结构以 JSON 单元格保留；JSON 使用 FeatureCollection。预览只截取前 12,000 字符，下载保留完整生成结果，重复点击下载不重新生成数据。

单站导出使用 fetchDownloadRecord 获取原始 GeoJSON。页面指南已更新为真实接口地址。已在浏览器以 0-22000-0-2501589 验证搜索条件同步、筛选 CSV 生成和单站原始 JSON 生成；未执行全库下载。构建和现有客户端回归测试通过。

## 首页与 WMDR 处理接入

首页快速搜索已移除本地示例兜底，站名和完整 ID 统一查询真实目录；接口失败显示错误与重试，取消旧请求避免旧结果覆盖。首页类型数量改为对 WMDR 已知类型逐一读取真实 numberMatched，统计非零类型数（不含 unknown），请求失败显示缺失与重试，不使用本地表长度。

维护页新增 WMDR 工具：按 ID 载入真实 JSON 后调用 pywmdr-wigos-wmdr2-ets；粘贴或读取 XML 后调用 pywmdr-wmdr2-migrate。两个接口均 POST /processes/{id}/execution?f=json，发送 inputs.record，使用同步原始响应。转换结果可下载或填入校验输入。输入仅在点击处理按钮后发送；工具不保存或发布站点，旧表单仍为演示。异步作业响应明确报错，不将其误当处理结果。

两个远端服务以公开记录 0-22000-0-2501589 实测 HTTP 200。官方校验返回 FAILED=2，并指出时间、邮箱及代码表问题；转换返回真实 Feature。回归测试覆盖真实请求体、失败校验结果保留、转换结果、异步响应处理、类型非零计数和统计请求错误。

## 官方 PDF 报告下载

地图与详情页已恢复 PDF，使用 OSCAR 官方服务。先 GET /oscar-station?wmoIndex={完整WIGOS标识} 解析 stationId，再 POST /oscar-pdf?registration=false，以表单字段 data 发送 JSON {id: stationId, imageUrl: ""}。下载前验证 %PDF- 文件头。不是前端演示 PDF；原始报告由 OSCAR 生成，未提供地图截图，报告可能不含地图图像。

开发/preview 代理和 nginx.conf 已增加两个固定路径，分别转发到 https://oscar.wmo.int/surface/rest/api/stations/station 和 https://oscar.wmo.int/surface/rest/api/stations/download/station。生产交付 dist 时必须同时更新 Nginx，只有旧 wmdr-source 配置不足以支持 PDF。公开站点 0-22000-0-7810046 经本地代理实测返回 HTTP 200、application/pdf、7134 字节、%PDF-1.4 文件头。此功能依赖 OSCAR 服务，不属于 WIGOS 目录接口。

## PDF 地图补齐（最新实现）

官方 imageUrl 接受远程图片 URL，不接受 data:image；官方公开 HighQualityMapExport 服务实测报错。当前采用浏览器合并方案：获取官方原始 PDF → 重新获取真实站点坐标 → 使用随 dist 分发的 Natural Earth 边界生成定位图 PNG → 通过 pdf-lib 保留官方报告并附加地图页。地图包含站点 ID、坐标、定位标记、周边边界、世界概览和来源说明。该地图是门户新增的定位图，不是官方报告原位地图截图。无坐标、边界加载失败、地图或 PDF 处理错误时明确提示，不静默下载缺图文件。

地图和详情页共用此流程，生产不增加新代理或图片上传服务，仍需现有 oscar-station、oscar-pdf 代理。pdf-lib 按需加载。已对 0-22000-0-7810046 实测合并为 6 页 PDF，末页包含嵌入图片，并渲染目视检查通过。新增测试：node --experimental-vm-modules tests/reportMap.test.mjs。此前文档中“可能不含地图”的说明已由本节替代。


## 地图分页与聚合修复（2026-11-06）

首页和搜索页地图共用独立的视野查询，每次请求 500 条，按 offset 持续读取至 numberMatched，不再受每类 60 条或列表 25 条限制。搜索地图使用相同筛选条件，但不使用列表页码。低于 zoom 6 时按约 45 像素网格在前端聚合并显示站点数，点击聚合点放大；zoom 6 起显示单站。聚合数量仅代表当前已加载数据，状态栏同时显示已加载/匹配数量和可定位站点数。全球视野仍需分页下载记录，尚未使用服务端聚合或矢量瓦片。

移动视野时取消旧请求，失败明确提示结果不完整并支持重试；移除地图演示点兜底。跨日期变更线暂扩大到全经度查询，保证不遗漏两侧站点。站点记录缺失类型或坐标时仍无法绘制，以可定位站点数与加载数区分。接口分页期间目录发生更新时，offset 分页仍可能受上游数据变化影响。

验证：npm run build；node --experimental-vm-modules tests/catalogue.test.mjs，新增覆盖 500 条分页、筛选和 bbox 传递、进度、请求失败、预取消及提前空页。未完成真实远端浏览器验收。

地图展示调整：聚合点不再显示数字，圆圈半径随聚合规模按对数增长并设上限；放大后按屏幕网格逐步拆分，zoom 6 起显示单站。地图状态不再展示数量，仅保留加载中、无匹配与失败重试提示。


## 无筛选地图使用矢量瓦片

首页及搜索页无关键词、类型、计划、地域、变量及区域筛选时，使用 GET C/tiles/WebMercatorQuad/{z}/{y}/{x}?f=pbf。注意路径是级别、行、列，即 z/y/x。使用OpenLayers MVT解析hits图层，按设施类型着色；悬停按记录ID查询完整详情。出现筛选条件则隐藏瓦片，切换GET C/items?f=json的视野内500条分页与前端聚合；清空条件恢复瓦片。列表和导出仍使用items。

瓦片入口和实际全球瓦片已实测HTTP 200，返回application/vnd.mapbox-vector-tile并允许CORS。全球测试瓦片仅含10000个hits，完整性尚未确认，不可将无筛选瓦片展示视作全库完整计数。瓦片国家查询参数实测未生效，故不用于筛选结果。现阶段按上游瓦片原样展示，前端不补造缺失站点。
