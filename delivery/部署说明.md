# OSCAR Surface 1.0.0 离线部署

本目录是交付文件模板。只有生成 oscar-surface-1.0.0-linux-amd64.tar 后才是完整交付包。

## 环境

目标服务器需安装 Docker Engine 和 Docker Compose v2，使用 Linux AMD64（常见 Intel/AMD x86_64）容器。Windows Docker Desktop 需切换到 Linux 容器。

## 启动

把本目录及镜像 tar 放到服务器同一目录，在该目录执行：

```bash
docker load -i oscar-surface-1.0.0-linux-amd64.tar
cp .env.example .env
# 在 .env 中填写 VITE_AMAP_SECURITY_JS_CODE，然后启动。
docker compose up -d
docker compose ps
```

访问 http://服务器IP:8080/ 。服务器需允许访问该端口。

修改端口：把 .env.example 复制为 .env，调整 HTTP_PORT，然后再次执行 docker compose up -d。

## 管理

```bash
docker compose logs --tail=100 web
docker compose restart
docker compose down
```

无需源码、Node.js、npm 或额外数据库。镜像包含 Nginx 和网页静态资源。
用户、编辑等部分功能是本地演示，浏览器本地数据不会随镜像交付。

## 网络与配置

离线导入和启动无需拉取镜像，但实时站点查询需要用户浏览器访问
https://wmo-resource-catalogue.labs.wis2dev.io，地图瓦片需要访问
https://tile.openstreetmap.org。站点详情和部分下载由容器代理访问
https://oscar.wmo.int，因此服务器也需具备相应外网连接。
外部数据服务的可用性不由本镜像保证。

VITE_WIGOS_API_BASE 是构建期配置，不能通过本目录 .env 修改；更换目录接口需重新构建镜像。

## 完整交付文件

- oscar-surface-1.0.0-linux-amd64.tar：预构建镜像
- compose.yaml：启动配置
- .env.example：端口及高德运行时安全密钥配置
- 部署说明.md：本说明
- LICENSE：项目及第三方资源说明
- SHA256SUMS.txt：镜像文件校验值（构建脚本生成）

## 三种在线底图

首页和站点搜索主地图默认使用 OpenStreetMap，无需 Key。高德和天地图切换后定位到中国，重置视图也返回中国范围。OpenStreetMap 使用全球视野。站点图层继续使用原有数据。

本地开发可复制根目录的 `.env.example` 为 `.env.local`，填写配置后重启 Vite。天地图使用 `VITE_TIANDITU_KEY`（即 `tk`）。高德使用 Web JS API 的 `VITE_AMAP_KEY`，生产部署还需配置高德安全代理并将其地址填入 `VITE_AMAP_SERVICE_HOST`。本地调试也可使用 `VITE_AMAP_SECURITY_JS_CODE`，该值会进入浏览器构建产物。高德安全代理的设置见[官方文档](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)。

Docker 镜像已包含高德 Nginx 安全代理。构建时传入 `VITE_TIANDITU_KEY` 和 `VITE_AMAP_KEY`，`VITE_AMAP_SERVICE_HOST` 默认使用本站的 `/_AMapService`。运行时在部署目录的 `.env` 中设置 `VITE_AMAP_SECURITY_JS_CODE`，Compose 将其作为 `AMAP_SECURITY_JS_CODE` 注入 Nginx。安全密钥由服务器代理附加到高德请求中。

天地图瓦片由浏览器携带 `tk` 直接请求，无需上述高德安全代理。浏览器需能访问天地图服务。

在源码目录执行 `./scripts/build-delivery.ps1` 可从 `.env.local` 读取地图 Key、构建并导出镜像。在本机使用源码目录配置启动可执行 `docker compose --env-file .env.local --file delivery/compose.yaml up -d`。更换高德 Key 或天地图 tk 需重新构建镜像。仅修改高德安全密钥时，更新部署环境配置并重建容器即可。
